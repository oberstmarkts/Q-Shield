# 5-Minute Demo Script

1. Show the project folder and README.
2. Run `python -m app.main --mode offline`.
3. Open `reports/q_risk_results.csv`.
4. Open `reports/q_shield_report.md`.
5. Run `python run_web.py`.
6. Open `http://127.0.0.1:8000`.
7. Explain Critical/High assets and recommendations.
8. Close with the expansion roadmap: Zeek/Suricata logs, OQS lab, CBOM.

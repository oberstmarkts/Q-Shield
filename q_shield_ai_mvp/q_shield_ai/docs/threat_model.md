# Threat Model

## 핵심 위협

Q-Day 이후 Shor 알고리즘 기반 양자컴퓨터가 RSA/ECC 공개키 암호를 무력화할 가능성에 대비합니다.

## 공격 시나리오

1. 외부 공개 서비스의 TLS 트래픽이 장기간 수집됩니다.
2. 현재는 복호화하지 못하지만, Q-Day 이후 과거 트래픽을 복호화합니다.
3. 인증정보, 개인정보, 금융정보, 업무기밀이 사후 노출됩니다.

## 방어 목표

- RSA/ECC 기반 공개키 자산 식별
- 외부 노출·민감도 기반 우선순위 산정
- PQC 전환 권고 자동화
- 리포트 기반 의사결정 지원

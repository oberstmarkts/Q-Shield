# Q-Shield

Q-Shield is a final project repository for the Goorm Information Security Expert Course.

## Project Direction

Q-Shield aims to build an AI-assisted intrusion detection and response support system. The project focuses on reproducible security operations, evidence-based analysis, detection-rule management, and practical team collaboration.

## Recommended Collaboration Model

- Organization: `q-shield-ai`
- Repository: `Q-Shield`
- Team: `q-shield-devs`
- Team permission: `Write`
- Initial visibility: `Private`
- Final visibility: `Public` after presentation and security review

## Branch Strategy

- `main`: stable branch for reviewed deliverables
- `dev`: integration branch
- `feature/*`: feature work branches
- `docs/*`: documentation branches

## Basic Rules

1. Do not commit secrets, passwords, API keys, tokens, or personal data.
2. Use pull requests for changes to `main`.
3. Request at least one review before merging.
4. Keep evidence and project decisions traceable through issues and commits.
5. Use clear commit messages and link issues where possible.
